# Minecraft Setup

## Client

- [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher) - An Open-Source, Multi-Instance, no Bloat, no Telemetry, no ads minecraft launcher.

## Mods (I use the [Fabric](https://fabricmc.net/) modloader)

- [Mod Menu](https://modrinth.com/mod/modmenu) - Adds a mod menu to view the list of mods you have installed. If supported by the mod, enables easier access to the mod's config screens.

- [Controlling](https://modrinth.com/mod/controlling) - Adds a search bar to the Key-Bindings menu.

- [No Chat Reports](https://modrinth.com/mod/no-chat-reports) - Removes user id signatures from your chat messages unless the server you join requires them. Additionally, this mod will also disable the usage data collection, aka telemetry, introduced in Minecraft 1.18.

- [Bypass resource pack](https://github.com/emilyy-dev/bypass-resource-pack) - Fabric mod to reject and bypass resource packs forced by servers.

- [Sodium](https://modrinth.com/mod/sodium) - A (really popular) performance optimization mod for Minecraft that enhances frame rates and reduces micro-stutter while fixing various graphical issues

- [Sodium Extra](https://modrinth.com/mod/sodium-extra) - Adds extra features and settings to Sodium

- [Reese's Sodium Options](https://modrinth.com/mod/reeses-sodium-options) - Replaces Sodium's options menu with a scrollable, searchable interface for better customization and UX.

- [Lithium](https://modrinth.com/mod/lithium) - Optimization mod that boosts server tick rates by improving game physics, mob AI, and block ticking.

- [Nvidium](https://modrinth.com/mod/nvidium) - NVIDIA-only rendering backend for Sodium, using mesh shaders to massively boost FPS and enable ultra-high render distances on 16xx series or newer GPUs. 
(At the time im writing this, Nvidium only supports minecraft versions up to 1.21.1 so i'm using [this fork](https://github.com/drouarb/nvidium))

- [Iris](https://modrinth.com/mod/iris) - Enables shader pack support with Sodium.

- [Distant Horizons](https://modrinth.com/mod/distanthorizons) - Renders low-detail (LOD) terrain far beyond vanilla view distance limit.

- [Lighty](https://modrinth.com/mod/lighty) - Visualizes light levels with color-codded overlays to spot mob spawn zones, toggleable via F7.

- [Fadeless](https://modrinth.com/mod/fadeless) - Removes fade out animations when starting the game or changing resource packs.

- [BoatView360](https://modrinth.com/mod/boatview360) - Allows full 360° camera rotation while seated in a boat.

- [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap) - Overlays a customizable map of nearby terrain, entities, and players in the screen corner.

- [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map) - Adds a fullscreen, zoomable map of explored terrain across dimensions (Overworld, Nether, End), with waypoint support and minimap integration.

- [Mouse Tweaks](https://modrinth.com/mod/mouse-tweaks) - Enhances inventory management by adding various functions to the mouse buttons.

- [Just Zoom](https://modrinth.com/mod/just-zoom) - Allows you to zoom by pressing a hotkey and adjust the zoom with your mouse wheel.

- [Freecam](https://modrinth.com/mod/freecam) - SOME SERVERS CONSIDER THIS CHEATING SO USE AT YOUR OWN RISK - Allows you to control your camera separately from your player. While it is enabled, you can fly around and travel through blocks within your render distance. 

- [Shulker Box Tooltip](https://modrinth.com/mod/shulkerboxtooltip) - allows you to see a preview window of all the  shulker boxes content, instead of the default short preview.

- [AppleSkin](https://modrinth.com/mod/appleskin) - Shows hunger and saturation values in the HUD.

- [Better Ping Display](https://modrinth.com/mod/better-ping-display-fabric) - Displays each player's ping in the player list as a number.

## Honorable mention

- [In-Game Account Switcher](https://modrinth.com/mod/in-game-account-switcher) - Allows you to change which account you are logged in to in-game, without having to restart Minecraft. (i dont personally use this one, as i only play on one account, but i have tested it and it works well)
